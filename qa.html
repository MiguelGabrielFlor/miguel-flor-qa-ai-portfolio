TC-019 Navegación entre páginas del portfolio

¿Qué verifica?

Comprueba la carga directa de las cinco páginas internas y la navegación a ellas mediante los enlaces visibles del portfolio, verificando la URL y el contenido principal.

Código Selenium

const paginas = [
                        'cv.html',
                        'frontend.html',
                        'backend.html',
                        'qa.html',
                        'quality-management.html'
                    ];

                    // Prueba 1: carga directa de cada página.
                    for (const pagina of paginas) {
                        await driver.get(`${BASE_URL}/${pagina}`);
                        await driver.wait(until.elementLocated(By.css('body')), 10000);
                        const url = await driver.getCurrentUrl();
                        assert.ok(url.endsWith(`/${pagina}`));
                        const contenido = await driver.findElement(By.css('main'));
                        assert.equal(await contenido.isDisplayed(), true);
                    }

                    // Prueba 2: navegación desde enlaces del portfolio.
                    for (const pagina of paginas) {
                        await driver.get(`${BASE_URL}/home.html`);
                        await driver.executeScript(
                            "sessionStorage.removeItem('portfolioSession');"
                        );
                        await driver.navigate().refresh();
                        // Se completa el formulario de acceso con datos válidos.
                        // Se espera hasta que #portfolio esté visible.
                        const enlace = await driver.wait(
                            until.elementLocated(By.css(`a[href="${pagina}"]`)),
                            10000
                        );
                        assert.equal(await enlace.isDisplayed(), true);
                        await enlace.click();
                        await driver.wait(until.urlContains(`/${pagina}`), 10000);
                        assert.ok((await driver.getCurrentUrl()).endsWith(`/${pagina}`));
                    }

TC-020 Retorno al perfil y a las secciones del Home

¿Qué verifica?

Verifica que el logo de cada página interna regrese a home.html y que los botones de retorno conduzcan a #about desde CV o a #qa desde las otras cuatro páginas, con la sección de destino visible.

Código Selenium

// Prueba 1: retorno mediante el logo.
                    for (const pagina of paginas) {
                        await driver.get(`${BASE_URL}/${pagina}`);
                        const enlace = await driver.wait(
                            until.elementLocated(By.css('a.logo[href="home.html"]')),
                            10000
                        );
                        assert.equal(await enlace.isDisplayed(), true);
                        await enlace.click();
                        await driver.wait(until.urlContains('/home.html'), 10000);
                        assert.ok((await driver.getCurrentUrl()).endsWith('/home.html'));
                    }

                    // Prueba 2: retorno mediante botones a secciones del Home.
                    const retornos = [
                        { pagina: 'cv.html', seccion: 'about' },
                        { pagina: 'frontend.html', seccion: 'qa' },
                        { pagina: 'backend.html', seccion: 'qa' },
                        { pagina: 'qa.html', seccion: 'qa' },
                        { pagina: 'quality-management.html', seccion: 'qa' }
                    ];

                    // Antes del recorrido se inicia una sesión válida.
                    for (const { pagina, seccion } of retornos) {
                        await driver.get(`${BASE_URL}/${pagina}`);
                        const boton = await driver.wait(
                            until.elementLocated(
                                By.css(`a.cv-back-button[href="home.html#${seccion}"]`)
                            ),
                            10000
                        );
                        assert.equal(await boton.isDisplayed(), true);
                        await boton.click();
                        await driver.wait(
                            until.urlIs(`${BASE_URL}/home.html#${seccion}`),
                            10000
                        );
                        assert.equal(
                            await driver.getCurrentUrl(),
                            `${BASE_URL}/home.html#${seccion}`
                        );
                        const destino = await driver.wait(
                            until.elementLocated(By.id(seccion)),
                            10000
                        );
                        await driver.wait(until.elementIsVisible(destino), 10000);
                        assert.equal(await destino.isDisplayed(), true);
                    }

Extractos de las dos pruebas reales. La segunda inicia una sesión válida antes de recorrer las cinco páginas y comprueba la visibilidad de cada sección de destino. Archivo: portfolio-navigation.test.js.
