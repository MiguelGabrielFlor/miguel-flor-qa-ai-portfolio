UI-002 Formulario vacío

¿Qué verifica?

Comprueba que los campos obligatorios muestren sus errores y que el portfolio permanezca oculto.

Código Selenium

await driver.findElement(
                                By.id('accessButton')
                            ).click();

                            const expectedErrors = {
                                firstNameError: 'El nombre es obligatorio.',
                                lastNameError: 'El apellido es obligatorio.',
                                emailError: 'El email es obligatorio.',
                                phoneError: 'El teléfono es obligatorio.',
                                consentError: 'Debés aceptar el registro de tus datos.'
                            };

                            for (const [errorId, expectedMessage] of Object.entries(expectedErrors)) {
                                const errorElement = await driver.findElement(By.id(errorId));

                                assert.equal(
                                    await errorElement.getText(),
                                    expectedMessage,
                                    `Mensaje incorrecto en ${errorId}`
                                );
                            }

                            const portfolio = await driver.findElement(By.id('portfolio'));

                            assert.equal(await portfolio.isDisplayed(), false);

UI-008 Registro válido y acceso al portfolio

¿Qué verifica?

Comprueba que el registro válido permita ingresar y que el saludo muestre el nombre en mayúsculas.

Código Selenium

await driver.findElement(By.id('firstName'))
                                .sendKeys('Miguel');

                            await driver.findElement(By.id('lastName'))
                                .sendKeys('Flor');

                            await driver.findElement(By.id('email'))
                                .sendKeys('selenium.test@example.com');

                            await driver.findElement(By.id('phone'))
                                .sendKeys('1123456789');

                            await driver.findElement(By.id('consent')).click();
                            await driver.findElement(By.id('accessButton')).click();

                            const portfolio = await driver.wait(
                                until.elementIsVisible(
                                    await driver.findElement(By.id('portfolio'))
                                ),
                                10000,
                                'El portfolio debería mostrarse después del registro válido.'
                            );

                            assert.equal(await portfolio.isDisplayed(), true);

                            assert.equal(
                                await driver.findElement(By.id('accessPage')).isDisplayed(),
                                false,
                                'El formulario de acceso debería quedar oculto.'
                            );

                            const welcomeMessage = await driver.findElement(
                                By.id('welcomeMessage')
                            );

                            assert.equal(
                            await welcomeMessage.getText(),
                            'Te doy la bienvenida, MIGUEL',
                            'El saludo debe mostrar únicamente el nombre en mayúsculas.'
                        );

¿Qué verifica?

const message = await driver.findElement(

                        By.id('contactStatus')

                    assert.equal(
                        await status.getText(),
                        'Mensaje enviado correctamente.'
                    );

                    assert.equal(
                        await message.getAttribute('value'),
                        ''
                    );

                    assert.equal(

                    );
UI-011 Validación de mensaje de contacto vacío

¿Qué verifica?

Comprueba que el formulario de contacto rechace un mensaje vacío mediante la validación HTML5. También verifica que no aparezca una confirmación de envío. No se comprueba directamente la ausencia de una solicitud HTTP.

Código Selenium

const contactButton = await driver.findElement(
                        By.id('contactButton')
                    );

                    await contactButton.click();

                    const messageField = await driver.findElement(
                        By.id('contactMessage')
                    );

                    const isInvalid = await driver.executeScript(
                        'return !arguments[0].checkValidity();',
                        messageField
                    );

                    assert.equal(
                        isInvalid,
                        true,
                        'El campo vacío debe ser inválido según HTML5.'
                    );

                    const error = await driver.findElement(
                        By.id('contactMessageError')
                    );

                    const errorText = await error.getText();

                    assert.ok(
                        errorText === '' ||
                        errorText === 'El mensaje es obligatorio.',
                        'No debe aparecer un mensaje inesperado.'
                    );

                    const status = await driver.findElement(
                        By.id('contactStatus')
                    );

                    assert.equal(
                        await status.getText(),
                        '',
                        'No debe mostrarse una confirmación de envío.'
                    );
UI-015 Manejo de error HTTP 500

¿Qué verifica?

Comprueba que, ante un fallo simulado del servicio de contacto, el formulario muestre el mensaje de error correspondiente, conserve el texto ingresado y vuelva a habilitar el botón de envío. No se envían correos reales.

Código Selenium

const message = await driver.findElement(
                        By.id('contactMessage')
                    );

                    const testMessage =
                        'Prueba Selenium: error HTTP 500 simulado.';

                    await message.sendKeys(testMessage);

                    const contactButton = await driver.findElement(
                        By.id('contactButton')
                    );

                    await contactButton.click();

                    const status = await driver.findElement(
                        By.id('contactStatus')
                    );

                    const expectedError =
                        'No se pudo enviar el mensaje. Intentá nuevamente más tarde.';

                    await driver.wait(
                        until.elementTextIs(status, expectedError),
                        10000
                    );

                    assert.equal(
                        await status.getText(),
                        expectedError
                    );

                    assert.equal(
                        await message.getAttribute('value'),
                        testMessage
                    );

                    assert.equal(
                        await contactButton.isEnabled(),
                        true
                    );
