¿Qué representa?

02. Validación y estados visuales

Comunicación visual de errores y campos en foco.

Estilos CSS

input:focus {
        border-color: var(--primary);

        box-shadow:
            0 0 0 3px
            rgba(108, 99, 255, 0.15);
    }

    input.input-error {
        border-color: var(--error);
    }

    .error-message {
        display: block;
        color: var(--error);
        font-size: 12px;
        margin-top: 6px;
    }

Gestión del error

js/app.js
JavaScript · showError 
function showError(
        input,
        errorId,
        message
    ) {
        input.classList.add("input-error");

        document.getElementById(
            errorId
        ).textContent = message;
    }

Explicación

¿Qué hace el CSS?

Resalta el campo activo y distingue los campos inválidos mediante el color de error. El mensaje se presenta debajo del campo correspondiente.

¿Qué hace JavaScript?

showError() agrega la clase de error al campo y coloca el mensaje en el elemento identificado por errorId.

¿Qué debería probarse?

  • Que el error aparezca en el campo correcto.
  • Que el mensaje sea claro y visible.
  • Que los errores puedan limpiarse.
  • Que el foco sea perceptible al navegar.
Enfoque QA Comprobar tanto la validación funcional como la presentación visual del error.

03. Internacionalización

Adaptación de los textos al idioma seleccionado.

Selección de idioma

js/app.js
JavaScript · applyLanguage 
function applyLanguage(language) {
        const selectedTranslations =
            translations[language] || translations.es;

        document.documentElement.lang = language;

        document.querySelectorAll("[data-i18n]")
            .forEach(function (element) {
                const key = element.dataset.i18n;

                if (selectedTranslations[key]) {
                    element.textContent =
                        selectedTranslations[key];
                }
            });

        document.querySelectorAll(
            "[data-i18n-placeholder]"
        ).forEach(function (element) {
            const key = element.dataset.i18nPlaceholder;

            if (selectedTranslations[key]) {
                element.placeholder =
                    selectedTranslations[key];
            }
        });
    }

Explicación

¿Cómo funciona?

La función obtiene las traducciones del idioma elegido y actualiza los elementos marcados con data-i18n y data-i18n-placeholder.

¿Por qué importa?

Cambiar el idioma implica más que traducir títulos: también deben actualizarse las etiquetas, los campos y los mensajes visibles.

¿Qué debería probarse?

  • Español, inglés y portugués.
  • Etiquetas y placeholders.
  • El atributo lang del documento.
  • Que cambiar el idioma no rompa el formulario.
Enfoque QA Ejecutar pruebas de regresión en los tres idiomas y comprobar que la interfaz mantenga su comportamiento.

Cobertura y resultados

¿Qué se automatiza?

Validaciones del formulario de acceso, consentimiento, registro válido, selección de idioma y comportamiento del formulario de contacto.

¿Cómo se ejecutan las pruebas?

Selenium WebDriver interactúa con la interfaz y Node.js Test Runner ejecuta las aserciones. Las pruebas de contacto utilizan una API Express con SQLite en memoria y un servicio de correo simulado, sin realizar envíos SMTP reales.
